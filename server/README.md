# خادم غرفة الصدفة

خادم Node.js وWebSocket سلطوي لغرف اللعبة. يدعم حتى 6 مقاعد في الغرفة الواحدة، ويحفظ الدور والشحنات السرية ونتيجة كل فعل على الخادم.

## تشغيل

```bash
pnpm install --frozen-lockfile
ALLOWED_ORIGINS=http://127.0.0.1:3000,http://localhost:3000 pnpm start
```

`GET /healthz` يعيد حالة الخادم. اتصال اللعب يكون على `/ws?room=ROOMCODE`.

## البروتوكول

يرسل الخادم `welcome` ثم `room` عند تغير حالة الغرفة. أثناء الجولة يرسل العميل `action` بإحدى القيم `self` أو `challenge` مع `target` أو `peek`. الخادم يعيد `result` لجميع اللاعبين ويحدد نوع الشحنة والهدف والدور التالي. رمز البروتوكول الحالي هو `chamber6-v1`.

## حدود النموذج الأولي

الغرف مؤقتة في الذاكرة وتنتهي بعد خمولها، وإعادة تشغيل الخدمة تسقط الغرف الحالية. رموز الغرف دعوات عامة وليست نظام حسابات. للنشر العام يجب تشغيل الخدمة خلف HTTPS/WSS، وتحديد أصول الواجهة بدقة في `ALLOWED_ORIGINS`.
