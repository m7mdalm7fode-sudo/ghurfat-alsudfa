# غرفة الصدفة

لعبة متصفح عربية أصلية مستوحاة من أجواء المخاطرة النفسية، وليست نسخة من أي لعبة أخرى. تدعم الغرفة من 2 إلى 6 لاعبين، وتعمل بواجهة RTL متجاوبة للموبايل والكمبيوتر.

## تشغيل النسخة المحلية

```bash
pnpm install
pnpm --dir server install --frozen-lockfile
ALLOWED_ORIGINS=http://127.0.0.1:3000,http://localhost:3000 pnpm dev:server
GAME_MULTIPLAYER_SIGNALING_URL=ws://127.0.0.1:8787/ws pnpm dev
```

افتح `http://127.0.0.1:3000` في متصفحين أو أكثر، استخدم رمز الغرفة نفسه، ثم ابدأ اللعب عند دخول لاعبين. الخادم يحتفظ بالشحنات السرية، صحة الأفعال، الدور، الإقصاء والنتيجة؛ المتصفح مسؤول عن العرض فقط.

## قواعد النموذج الأولي

تُجهّز الجولة بشحنات آمنة وخطرة. في دورك يمكنك السحب على نفسك، تحدي لاعب آخر، أو استخدام «البصيرة» لمعرفة أعداد الشحنات المتبقية. الشحنة الخطرة تخرج الهدف من الجولة، والآمنة تنقل الدور. آخر لاعب حي يفوز بالجولة ويحصل على نقطة.

## الأوامر

- `pnpm build` يبني نسخة الإنتاج ويتحقق من TypeScript وحجم الحزمة.
- `pnpm typecheck` يشغّل فحص TypeScript فقط.
- `pnpm dev:server` يشغّل خادم الغرف المحلي.

## النشر العام

الخادم الموجود في `server/` يحتاج خدمة Node.js عامة خلف WSS. بعد توفير Cloud Computer، يجب نشر الخادم، إضافة أصل الواجهة إلى `ALLOWED_ORIGINS`، ثم وضع عنوان `wss://.../ws` في `public/multiplayer/bootstrap.json` قبل نشر الواجهة.
